# 成員 D 個人紀錄

## 1. 基本資料

- 角色：課表與活動負責人
- 責任：課表矩陣、場地安排、活動資料

## 2. 本週工作內容

- 確認課表與活動的時間軸與資料格式。
- 定義週課表矩陣與時段分段方式。
- 匯整活動資料與課程之間可能的排程關係。

## 3. 主要成果

- 完成課表結構規格與排程方向。
- 建立活動安排的整體理解。
- 為後續課表生成奠定基礎。

## 4. 遇到的困難

- 團隊需同時考慮課程、活動與教室的限制，避免資料過度耦合。
- 有些安排在邏輯上可行，但會影響整體可讀性。

## 5. 下週計畫
