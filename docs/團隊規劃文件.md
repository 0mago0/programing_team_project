# 校園選課專題團隊規劃文件

## 1. 專案基本資料

- 專題名稱：校園選課專題（Campus Course Planner）
- 開發語言：Python 3
- 專案範圍：第 5 週最小可交付版
- 開發目標：建立可擴充的校園選課、衝堂檢查、課表與活動管理雛形

## 2. 團隊組成與分工

| 角色 | 成員 | 責任範圍 | 主要任務 |
| --- | --- | --- | --- |
| A | 組長/整合 | 專案總控、Git、README、主流程 | 建立專案骨架、版本管理、整合成果 |
| B | 資料管理 | 課程/學生/教室資料模型 | 建立資料結構、資料規格與資料一致性 |
| C | 選課限制與篩選 | 衝堂與規則邏輯 | 定義選課條件、衝突判斷、篩選邏輯 |
| D | 課表與活動 | 課表與場地安排 | 規劃時間表、活動資料、時間矩陣 |
| E | 搜尋與效能 | 最佳課表比較 | 搜尋策略、條件比較、效能優化 |
| F | 路徑與事件 | 移動與重規劃 | 路線、事件與動態調整設計 |

## 3. 工作流程

1. 先明確需求與資料格式。
2. 建立最小可執行骨架與測試基線。
3. 依角色分工實作各模組。
4. 定期檢查整合、衝突與錯誤。
5. 每週整理紀錄與交付成果。

## 4. 協作規範

- 每個模組都需有人主責，並由其他成員 Review。
- 變更必須保留版本紀錄；必要時由組長整合。
- 測試先行：新增核心功能至少應先新增測試。
- 每位成員需保留個人工作紀錄與實作檔案。
- 若資料格式或需求有變更，應先更新規格文件，再實作。
