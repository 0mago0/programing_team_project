# 成員 C 個人紀錄

## 1. 基本資料

- 角色：選課限制與篩選負責人
- 責任：衝堂檢查、選課規則、篩選邏輯

## 2. 本週工作內容

- 梳理選課限制條件與衝突判斷。
- 確認何種情況屬於不可選、須警示或需要自動重排。
- 定義正常與邊界狀況下的讀取規則。

## 3. 主要成果

- 完成規則類型與條件整理。
- 建立衝堂判斷邏輯的思路與風險清單。
- 協助後續模組實作篩選條件。

## 4. 遇到的困難

- 不同限制條件可能互相重疊，需有優先順序。
- 部分規則需要在資料驗證層與選課邏輯層分開處理。

## 5. 下週計畫

- 建立更完整的限制條件測試案例。
- 與 B、D 角色共同檢查資料與課表衝突。
- 釐清是否需加入自動修正模組。
