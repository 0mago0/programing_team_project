# F1 函式介面（第 6 週）

程式位置：`campus_planner/data_manager.py`、`campus_planner/validation.py`。
測試位置：`tests/test_f1_data_management.py`、`tests/test_f1_catalog.py`。

## 共通約定

- 所有函式都把 `SchoolCatalog` 當參數傳入，不使用全域變數，不呼叫 `input()`。
- **新增／修改**回傳 `list[str]` 錯誤清單；空清單代表成功。一次列出所有錯誤，不會停在第一個。
- **失敗時資料不變**：驗證全部通過才寫入 catalog。
- **刪除**回傳 `bool`：`True` 為已刪除，`False` 為不存在或受保護而拒絕。
- **查詢**回傳清單，依代號排序；沒給的條件不篩選，多個條件同時成立才列入。
- 選課人數只以學生的 `enrolled_courses` 計算（唯一資料來源），不另存計數。

## 資料容器

```python
@dataclass
class SchoolCatalog:
    courses: dict[str, Course]        # key = course_id
    students: dict[str, Student]      # key = student_id
    classrooms: dict[str, Classroom]  # key = room_id
```

## 課程

| 函式 | 輸入 | 輸出 | 錯誤／邊界 |
| --- | --- | --- | --- |
| `add_course(catalog, course)` | Course | 錯誤清單 | 代號重複、欄位空白、學分非正整數、人數上限 < 1、星期不在 1–7、節次不在 1–9/a/b/c、同課程時段重複 |
| `update_course(catalog, course_id, **changes)` | 要改的欄位 | 錯誤清單 | 課程不存在、改 `course_id`、未知欄位、新值不合法、人數上限小於目前選課人數 |
| `delete_course(catalog, course_id)` | 代號 | bool | 有學生選修 → False |
| `cancel_course(catalog, course_id)` | 代號 | 被退選的學號清單 | 課程取消程序：先替所有學生退選再刪除 |
| `find_courses(catalog, course_id=, teacher=, day=, required=, min_remaining=)` | 任意條件 | `list[Course]` | `course_id` 為前綴比對；`day` 只要任一時段在該星期即符合 |
| `enrolled_count(catalog, course_id)` | 代號 | int | |
| `remaining_seats(catalog, course_id)` | 代號 | int | 額滿為 0 |

## 學生

| 函式 | 輸入 | 輸出 | 錯誤／邊界 |
| --- | --- | --- | --- |
| `add_student(catalog, student)` | Student | 錯誤清單 | 學號重複、欄位空白、學分上限非正整數、已選課程重複或不存在 |
| `update_student(catalog, student_id, **changes)` | 要改的欄位 | 錯誤清單 | 學生不存在、改 `student_id`、新值不合法 |
| `delete_student(catalog, student_id)` | 學號 | bool | |
| `find_students(catalog, student_id=, department=, course_id=)` | 任意條件 | `list[Student]` | `student_id` 為前綴比對；`course_id` 找出選修該課的學生 |

## 教室

| 函式 | 輸入 | 輸出 | 錯誤／邊界 |
| --- | --- | --- | --- |
| `add_classroom(catalog, classroom)` | Classroom | 錯誤清單 | 代號重複、代號或建築物空白、容量非正整數 |
| `update_classroom(catalog, room_id, **changes)` | 要改的欄位 | 錯誤清單 | 教室不存在、改 `room_id` |
| `delete_classroom(catalog, room_id)` | 代號 | bool | 仍有課程使用 → False |
| `find_classrooms(catalog, building=, min_capacity=, equipment=)` | 任意條件 | `list[Classroom]` | `equipment` 需全部具備 |

## JSON 存取（給 F6 延伸）

| 函式 | 說明 |
| --- | --- |
| `load_catalog(path)` | 回傳 `(catalog, errors)`。JSON 壞掉回傳空 catalog 加錯誤；單筆資料錯誤只略過該筆並記錄，不會中止 |
| `save_catalog(path, catalog)` | 寫出課程、學生、教室三類資料 |
| `catalog_from_dict` / `catalog_to_dict` | dict 與 dataclass 互轉；載入順序為教室 → 課程 → 學生 |

## 使用範例

```python
from campus_planner.data_manager import SchoolCatalog, add_course, find_courses
from campus_planner.models import Course, TimeSlot

catalog = SchoolCatalog()
errors = add_course(catalog, Course("CS101", "Python 程式設計", 3, True, "林老師", 30, "A101",
                                    [TimeSlot(1, "3"), TimeSlot(1, "4")]))
assert errors == []
find_courses(catalog, teacher="林老師", day=1)
```
