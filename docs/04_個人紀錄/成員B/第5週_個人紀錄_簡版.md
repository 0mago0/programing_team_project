# 成員 B 個人紀錄

## 1. 基本資料

- 角色：資料管理負責人
- 責任：課程、學生、教室資料模型與資料一致性

## 2. 本週工作內容

- 確認資料類型與資料格式定義。
- 建立課程、學生與室場的雛型資料結構。
- 確認選課系統中的核心屬性與規則。

## 3. 主要成果

- 完成必要資料物件定義。
- 為後續模組建立共同資料標準。
- 協助規劃衝堂與篩選邏輯所需資料。

## 4. 遇到的困難

- 需要先界定資料真實邏輯，再設計校內場地與選課限制。
- 若資料格式不同，後續整合將變得困難。

## 5. 下週計畫

- 擴充資料條件驗證與邊界值檢查。
- 對接主要選課流程與錯誤處理。
- 與 C 角色共同確認限制條件優先順序。
