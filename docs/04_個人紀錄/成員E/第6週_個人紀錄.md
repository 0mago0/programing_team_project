## 3. 程式理解說明

選一個本週參與的重要函式，用**自己的話**說明。可選：`add_course`、`update_course`、`delete_course`、`cancel_course`、`find_courses`、`remaining_seats`、`validate_course`、`catalog_from_dict`。

| 項目 | 說明 |
| --- | --- |
| 函式名稱 | `find_courses(catalog, course_id, teacher, day, required, min_remaining)`。選它是因為我負責搜尋功能（F7 最佳課表搜尋），之後找可行課表時會先用它篩選候選課程。 |
| Input | `catalog`（存放所有課程、學生、教室的 SchoolCatalog），以及 5 個可以不給的條件：課程代號前綴、教師、星期、是否必修、最少剩餘名額。 |
| Process | 逐一檢查每門課，有給的條件都要符合，只要一個不符合就跳過；沒給的條件不篩選。代號用 `startswith` 比對，輸入 "CS" 會找到所有 CS 開頭的課。星期是只要課程任何一個時段在那天就算符合。剩餘名額用 `remaining_seats` 計算，也就是人數上限減掉已選這門課的學生人數。最後依課程代號排序，讓輸出固定、方便測試。 |
| Output | 符合條件的 Course 清單。例如用我的範例資料查 `teacher="林老師"`，得到 CS101、CS102。 |
| Boundary／Error Case | 1. 完全不給條件：回傳全部 20 門課。<br>2. `min_remaining=1`：會排除已額滿的 PE101。<br>3. `day=7`：只找到星期日上課的 CS199。<br>4. 沒有課程符合：回傳空清單，不會出錯。<br>5. 多個條件同時給要全部符合，例如星期一且必修，只得到 CS101、CS105。 |
