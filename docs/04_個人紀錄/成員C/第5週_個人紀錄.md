## 四、程式理解說明（預計實作之 slots_overlap）

<!-- widths: 20,80 -->
| 項目 | 說明 |
| --- | --- |
| Input | 兩個時段清單，每個時段為 {"day": 1～7, "period": "1"～"9"\|"a"\|"b"\|"c"}。 |
| Process | 驗證時段合法 → 轉成 (day, period) 集合取交集 → 依星期、節次順序排序。 |
| Output | {"ok","data","errors"}；ok=True 時 data 為重疊時段（空清單＝無衝突）。 |
| Boundary／Error | 空清單視為無衝突；重複時段去重；星期 0/8、節次 "d"、缺欄位 → E_BAD_SLOT；非清單 → E_BAD_FORMAT；皆不拋例外。 |
