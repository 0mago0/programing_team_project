# 成員 F 個人紀錄

## 1. 基本資料

- 角色：路徑與事件負責人
- 責任：地理路徑、移動規劃、動態事件處理

## 2. 本週工作內容

- 確認路線資料與事件情境定義。
- 整理學校場域間的移動需求與時間成本。
- 評估動態事件如何影響選課與課表安排。

## 3. 主要成果

- 建立路徑與事件模組的設計方向。
- 定義各項事件對時間安排的影響方式。
- 協助後續規劃重排與上課最適路線。

## 4. 遇到的困難

- 移動與事件邏輯容易擴大範圍，需收斂成最小可用版本。
- 若事件處理不清楚，後續功能整合會有非預期依賴。

## 5. 下週計畫

- 界定事件類型與處理流程。
- 與 D 角色驗證課表與路徑重排關聯。
- 在系統中加上可追蹤的事件輸出。
