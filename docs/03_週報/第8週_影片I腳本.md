# 影片 I 腳本與附件清單

從需求分析到可執行系統——我們如何與生成式 AI 協作｜第 15 組｜長度 6～8 分鐘

## 一、主題

**F2 多層次衝堂檢查：如何一次列出所有衝突，而不是找到第一個錯誤就停下來。**

選這個主題的原因：它是 F1～F6 中規則最多的功能（學生衝堂、活動衝突、教室衝堂、學分、額滿），而且團隊從第 5 週的草稿、第 6 週的錯誤額滿判斷，到第 7 週的完整版本都有程式與測試紀錄，每一步都能用 git 歷史與測試結果追溯。

作業規定 I-4 要呈現至少兩輪 Prompt，且影片內容必須能由繳交資料追溯，**不能事後重寫 Prompt 代替原始紀錄**。目前可追溯的紀錄：

## 四、錄製方式

- 畫面以螢幕錄影為主：程式碼、終端機執行結果、測試結果、對話截圖。
- 每段開頭說「我是成員 X，負責……」，讓老師分辨每位成員都有參與說明。
- 作業未規定必須露臉；若不露臉，建議片頭或片尾放團隊討論照片，並先向老師或助教確認。
